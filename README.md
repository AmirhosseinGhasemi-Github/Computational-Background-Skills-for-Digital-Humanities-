## About This Repository

This repository contains practical exercises and projects completed as part of the course *Computational Background Skills for Digital Humanities*.

It includes two main sections: Regular Expressions (Regex) and Web Development. The purpose of these exercises is to develop computational skills and gain practical experience with different programming and web technologies relevant to Digital Humanities.

## 1. Regex Exercises

### Project Description

This section contains exercises on Regular Expressions (Regex), focusing on text analysis and pattern matching.

The exercises are based on the novel *Pride and Prejudice* by Jane Austen (https://www.gutenberg.org/cache/epub/1342/pg1342.txt ). The objective was to use regular expressions to identify and extract specific patterns from the literary text.

### Tasks

- **Chapter Headings:** Identifying and extracting chapter headings using regular expressions.
- **Dialogue Extraction:** Finding and extracting quoted dialogue from the novel.
- **Person Names:** Identifying potential character names and extracting their surnames.

### Tools Used

- Regex101
- Regular Expressions

## 2. Web Development Project

This section contains my web development exercises, including the development of an artist portfolio website; using HTML, CSS, and JavaScript.

The website consists of different pages that introduce the artist, present her projects, and provide information about her works.
